# Инструкции Codex для проекта закупок

## Назначение

Поддерживай книгу планирования продуктов, напитков, покупок и готовки для выезда с пятницы вечером по воскресенье в обед. Основная актуальная книга: `outputs/закуп_тимбилдинг/План_закупок_тимбилдинг_свод.xlsx`.

## Логика книги

- Участники: 6 взрослых и 3 ребёнка. Детская порция по умолчанию равна 60% взрослой.
- Меню содержит два завтрака, два обеда и два ужина.
- Лист `План`: редактируемые число взрослых, число детей, доля детской порции, меню и список имён. Распределяй готовку только между взрослыми; каждому назначай один приём пищи ведущим и один приём пищи помощником.
- Лист `Закупки`: подробные продукты и напитки с количеством на взрослую порцию, единицей измерения, расчётным общим количеством, покупателем и отметкой о покупке.
- Лист `Итого к покупке`: объединённые по названию и единице продукты с формулами `SUMIFS`, без разбивки по дням и приёмам пищи.

## Правила изменений

- Сохраняй русские названия листов и существующий смысл формул.
- При добавлении продукта внеси его в `Закупки` и добавь название с единицей измерения в свободную строку `Итого к покупке`.
- Текущие формулы свода охватывают строки `Закупки!5:68`. Если список расширится за этот диапазон, расширь диапазоны формул свода.
- При изменении численности или состава участников проверь эквивалент порций, все расчётные количества и распределение ответственности.
- Сохраняй подробный список по приёмам пищи и общий свод как разные представления одной закупки.
- После правок пересчитай книгу, проверь формулы и отображение листов, затем сохрани результат в `outputs/закуп_тимбилдинг/`.
