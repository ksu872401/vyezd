# План закупок для тимбилдинга

Рабочая книга для выезда с пятницы вечером по воскресенье в обед: 6 взрослых, 3 ребёнка, два завтрака, два обеда и два ужина.

## Актуальная книга

Открой `outputs/закуп_тимбилдинг/План_закупок_тимбилдинг_свод.xlsx`.

- **План** — меню, количество участников и распределение готовки. Имена можно заменить на реальные.
- **Закупки** — список продуктов по приёмам пищи с количеством, покупателем и отметкой «Куплено».
- **Итого к покупке** — общий список продуктов на весь выезд; одинаковые позиции суммируются по названию и единице измерения.

## Как редактировать

- На листе **План** меняй жёлтые ячейки с числом взрослых, числом детей и долей детской порции. Стартовая доля — 60%.
- На листе **Закупки** меняй продукт, единицу или количество на одну взрослую порцию. Итоговое количество пересчитывается автоматически.
- Для новой позиции заполни свободную строку на листе **Закупки** и назначь покупателя. Затем внеси то же название и единицу измерения в свободную строку листа **Итого к покупке**.
- Отметки о покупке ведутся в подробном списке. В своде отражаются только названия, единицы и итоговые количества.
- Если закончились свободные строки, расширь таблицу и формулы свода, чтобы диапазоны покрывали новые позиции.

Количество продуктов ориентировочное. Перед покупкой округли его вверх под размер упаковок и проверь, подходят ли блюда участникам.
