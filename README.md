# Полевой стол — сайт меню и закупок

Небольшой сайт для планирования питания и покупок на выезд с пятницы вечера по воскресенье в обед. Работает как статический сайт и подходит для GitHub Pages: сервер и сборка не нужны.

## Публикация через GitHub Pages

1. Создайте GitHub-репозиторий.
2. Загрузите в него эту папку `docs` целиком. В репозитории должны появиться `docs/index.html`, `docs/styles.css`, `docs/app.js`, `docs/README.md` и `docs/plan-zakupok.xlsx`.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/docs`, затем нажмите **Save**.
5. После публикации GitHub покажет адрес сайта в настройках Pages.

Если в репозитории ещё нет ветки `main`, сначала добавьте файлы в главную ветку, которую создал GitHub.

## Возможности

- Меню на 6 приёмов пищи с редактируемыми блюдами.
- Настройки числа взрослых и детей и доли детской порции.
- Равномерное назначение взрослых на готовку: каждый ведёт один приём пищи и помогает на другом.
- Редактирование, добавление и удаление продуктов; покупатель и отметка о покупке.
- Автоматический общий список по названию продукта и единице измерения без разбивки по блюдам.
- CSV-выгрузка общего списка и подробных закупок.
- Скачивание итоговой книги Excel с главной страницы.
- JSON-резервная копия и восстановление данных.
- Автосохранение в `localStorage` браузера.

## Важно

Данные сайта хранятся локально в браузере пользователя и не синхронизируются между устройствами или участниками. Для переноса скачайте JSON-копию и загрузите её на другом устройстве. Не добавляйте персональные данные в публичный репозиторий.

Кнопка Excel скачивает файл `plan-zakupok.xlsx`, лежащий рядом с сайтом в папке `docs`.
